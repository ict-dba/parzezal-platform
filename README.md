# parzezal-
## Purpose

This repository documents the evolution of my personal infrastructure platform.

The platform is intentionally built to explore:

- Site Reliability Engineering
- Platform Engineering
- Infrastructure Automation
- Observability
- Disaster Recovery
- Security

While inspired by production practices, configurations are designed for a small-scale home environment running on a Raspberry Pi.

A self-hosted platform engineering and reliability laboratory built on Raspberry Pi, Docker, and open-source technologies.
